## Goal
One CRM section fully brainstormed (25+ answered questions, decisions recorded in Isa's choices), then built and tested, before moving to the next.

## Context
- Section map and status: projects/crm/sections.md. Read it first; pick up where we left off.
- Each section's file: projects/crm/sections/NN-<name>.md (questions, Isa's answers, decisions, build notes).
- Project background: context/priorities.md, context/about-business.md. Detailed criteria live in Isa's apprenticeship Claude Project.

## Steps
1. Open the current section file (create from the format below if new). Say which section and why it is next.
2. Brainstorm: at least 25 questions, in batches of 5. Each question has:
   - options A, B, C (short, concrete, different from each other)
   - a recommendation (★) with a one-line reason
   Isa answers like "1B 2A 3 other: ...". Save answers to the file after every batch.
   Later batches build on earlier answers; skip questions already answered; go deeper where answers raise new issues.
3. After 25+: write a short "Decisions" summary in Isa's choices (no new decisions), and list open questions. Ask Isa to confirm.
4. Log the key decisions in decisions/log.md and projects/crm/sections.md.
5. Build the section (smallest working version first), test it, show Isa, fix. Record build notes.
6. Mark the section done in sections.md; suggest the next one.

## Rules
- Isa decides. Recommendations are advice; never treat ★ as chosen unless Isa picks it.
- Assessment integrity: reasoning for assessed write-ups is Isa's own words; mark [ISA TO WRITE].
- Risks to check every section: UK GDPR / marketing consent, fairness (purchase history only, no name/area targeting), salesmen trust (no performance league tables), human approval before emails, made-up data in designs.
- Keep each batch scannable: one line per option.
