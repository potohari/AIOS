name: level-up
description: Finds the next thing worth building in the AIOS via a short interview, then ranks proposals as new skills, connections or fixed automations. Use when the owner asks "what should I automate next?", "level up", "what next", or after an audit.
---

## Goal
A ranked list of 3-7 proposals, each tagged [skill], [connection] or [automation], saved to expansions.md.

## Steps
1. Read context/priorities.md, about-me.md (pains), connections.md, the latest audit, expansions.md.
2. Phase one interview, ONE question at a time:
   1. Repetition: walk me through last week. What did you do three or more times?
   2. Drudgery: what felt manual, boring or copy-and-paste?
   3. Smart-intern test: what could a capable intern have done, but you did it yourself because explaining took longer?
   4. Constraint: if 500 new customers arrived on Monday, what would break first?
   5. Growth lever: what would bring 500 more clients if it ran on autopilot?
   If connections exist, pre-fill answers from live data and ask him to confirm.
3. Phase two, apply the Method (references/three-ms.md): for each candidate, is it worth automating (frequency x time x pain x link to priorities), how far (what % can AI do), cheapest proof version, and whether a fixed script beats an agent.
4. Output a ranked table: rank | proposal | tag | why (tie to a priority) | cheapest first version | owner input needed.
5. Append to expansions.md with today's date; log the chosen next step in decisions/log.md.

## Rules
- Prefer fixed automations when the steps never change ("boring is beautiful").
- A missing connection that blocks several skills ranks above any single skill.
