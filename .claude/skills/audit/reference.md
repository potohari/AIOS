# Audit scoring rules [filled in]

Each pillar is 25 points. Award points per line; total per pillar is capped at 25.

## Context (25)
- 5 about-me.md specific (role, background, pains), no placeholders
- 5 about-business.md specific (offer, ideal customer, services, revenue model, team)
- 5 priorities.md current (updated within ~90 days, measurable outcomes)
- 4 voice.md has real samples + style notes
- 3 CLAUDE.md "Where things live" matches the real folder layout
- 3 decisions/log.md has an entry in the last 14 days

## Connections (25)
- 3 per tier-one domain (Revenue, Customer, Calendar, Comms, Tasks, Meetings, Knowledge) that is connected AND tested (max 21)
- 2 every connected tool has references/<tool>-api.md
- 2 keys only in .env, .env.example in sync, least-privilege keys used, connections.md accurate

## Capabilities (25)
- 4 per owner-built skill beyond the four starters (max 16)
- 4 those skills were used/updated in the last 14 days (git log or decisions log)
- 3 skills have Rules and References sections (lessons captured)
- 2 every skill listed in CLAUDE.md; sub-agents used where heavy search occurs

## Cadence (25)
- 7 at least one recurring scheduled run exists
- 5 project pushed to a private remote (backup)
- 5 scheduled runs tested (Run now) and reported results
- 4 failure alerts in every scheduled prompt
- 4 daily + weekly rhythm in use (morning plan / Friday audit evidence)

## Bands
0-25 just started | 26-50 foundation | 51-75 working system | 76-100 operating system
